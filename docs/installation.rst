Installation
============

Download QClip from `QClip Releases <https://github.com/zerovoxxx/QClip/releases>`__.
Windows provides an x64 installer and a portable ZIP; macOS provides Intel and
Apple Silicon DMGs for macOS 13 or newer.

Install, permission and troubleshooting instructions are maintained in the
`QClip user guide <https://github.com/zerovoxxx/QClip/blob/master/docs/USER_GUIDE.md>`__.
The current release has no commercial Windows code signature or Apple Developer ID notarization.

Linux is supported from source. This release does not provide Linux binaries.
CopyQ package-manager entries install the upstream product, not QClip.
